# Estándar de presentación del producto

- Fotografías relevantes al comercio de productos frescos.
- Jerarquía clara entre identidad, acción principal y datos operacionales.
- Texto alternativo en imágenes informativas.
- Carga diferida fuera del hero.
- Respaldo visual en componentes dinámicos.
- Consistencia entre tienda pública y superficies internas.
- No usar imágenes de personas o negocios reales como si fueran clientes del producto.
